# Biz-DNA 소상공인 통합 경영진단 MVP

## 실행
Python 3.10 이상 설치 후:

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저의 로컬 주소(보통 http://localhost:8501)로 접속합니다.

## 구현 기능
- 점포정보 및 월 매출·비용·임대료 입력
- DNA 4개 축 × 4문항 = 16문항 → 16개 유형 코드
- 8대 경영역량 × 4문항 = 32문항 → 가중 종합점수
- 적자·임대료 과다·재무역량 취약 규칙 탐지
- 업종·역량격차·재무위험 반영 전략 우선순위 추천
- Streamlit 대시보드 및 PDF 기본형/정밀형 다운로드
- JSON 진단결과 다운로드, 가상기업 2개 예시

## 제한사항
- 정밀형은 규칙기반 심층보고서이며 외부 생성형 AI API 호출은 포함되지 않음
- 상권/카드매출/공공데이터 실시간 연계 미구현. 실제 데이터는 점주 직접 입력
- 로그인·DB·다중사업장·관리자 기능 미구현
- 가중치·진단기준·위험 임계값은 실증 전 가설
- 월 매출-비용 차액은 세무상 영업이익이 아님
- 서비스 공개 시 개인정보·사업정보 보안, 동의, 권한관리 추가 필요

## 자동화 연계
`engine.diagnose(payload)`가 JSON 직렬화 가능한 결과를 반환합니다. `report.build_pdf(result, detailed=True)`가 PDF bytes를 반환합니다. API 및 외부 AI 서술 모듈은 이 경계에 연결하는 방식 권장.
