# Biz-DNA 소상공인 v4.0 (시범모형)

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 주요 파일
- `engine.py`: v3 공통 진단엔진, DNA 16유형, 8대 역량, 위험신호, 전략추천
- `advanced.py`: 업종별 12개 추가문항, 업종 가중치, 실적 기반 잠정 성장단계, 입력자료 충족도
- `app.py`: 점주용 Streamlit 웹 설문, 결과 차트, PDF 다운로드
- `report.py`: 기본형·정밀형 PDF 자동생성
- `test_v4.py`: 두 가상점포의 입력·진단·PDF 테스트
- `sample_*.json`: 가상 사례 (실제 기업정보 아님)

## 데이터 해석상 주의
- 금액 단위: 만원/월. 총비용은 임대료 포함. 매출-비용 차액은 회계상 이익이 아님.
- DNA 16유형, 영역 가중치, 위험 임계값, 성장단계 판정은 미검증 시범기준.
- 업종별 심화 12문항은 기존 32문항 중 대응하는 3개 영역에 35% 가중 반영.
- 성장단계 판정은 선택 실적자료 모두 입력된 경우에만 잠정 수행하며 S5는 별도 증빙 없이 판정하지 않음.
- 외부 카드매출/상권 API, 생성형 AI, 계정인증/DB, 운영환경 보안은 미구현.
- 동종업종 비교는 외부 공식 통계가 없으므로 자동으로 생성하지 않음.
